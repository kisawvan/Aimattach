# Aimattach

基于 RoboMaster SDK、YOLOv5 与 OpenCV 霍夫圆检测的云台视觉跟踪实验。

## 项目内容

[aim.py](aim.py) 将相机取流、目标检测、局部圆检测和云台控制串接在同一脚本中，适合阅读视觉到执行器的基础控制流程。

- `YOLODetector`：通过 `torch.hub.load('ultralytics/yolov5', 'custom', ...)` 加载自定义权重，筛选置信度高于 0.5 的结果。
- `HoughCircleDetector`：灰度化、高斯滤波后进行霍夫圆检测，并将 ROI 坐标还原到原图。
- `RobotTracker`：选择第一个类别为 `person` 的检测框，在其周围扩展 20 像素检测圆。
- 只有同时检测到目标和圆时才控制云台；跟踪点使用目标框中心，圆检测用于触发条件。
- 显示检测框、圆和图像中心，按 `q` 退出；入口默认跟踪 30 秒。

## 运行准备

需要支持 RoboMaster SDK 的机器人、可通信的网络和能够显示 OpenCV 窗口的 Python 环境。代码依赖 `torch`、`numpy`、`cv2`、`robomaster`，仓库暂未固定 Python 与依赖版本，也未提供依赖锁文件。

1. 按设备和计算环境准备上述依赖；首次通过 Torch Hub 加载时还需获取 YOLOv5 代码及相关依赖。
2. 将兼容的模型权重放在运行目录中，或修改入口的 `yolo_model_path`。
3. 根据设备网络配置核对 `ep_robot.initialize(conn_type="sta")`。
4. 确认模型类别名称包含 `person`，或修改 `target_class`。
5. 从仓库根目录启动：

```bash
python aim.py
```

## 关键参数与当前边界

| 参数 | 代码默认值 | 说明 |
| --- | --- | --- |
| 图像中心 | `(640, 360)` | 按 1280×720 假设设置，应与实际视频尺寸匹配 |
| 水平比例 | `yaw = -dx * 0.1` | 每次角度指令限幅 ±30° |
| 俯仰比例 | `pitch = -dy * 0.05` | 每次角度指令限幅 ±20° |
| 霍夫圆半径 | `10..100` 像素 | 需按距离和目标大小调整 |
| `follow_threshold` | `50` | 已声明，但当前跟踪逻辑未使用 |

当前控制使用阻塞式 `move(...).wait_for_completed()`，不能把循环中的 0.1 秒等待等同于固定控制周期。仓库未提供训练数据、模型、精度统计或实机跟踪记录；当前内容说明代码结构，不代表已经完成性能或硬件验收。
